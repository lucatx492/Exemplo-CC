# Exemplo-CC

Repositório de exemplo utilizado durante o curso de **Claude Code**.

## Sobre o Projeto

Este repositório serve como ambiente de prática para explorar as funcionalidades do Claude Code, o CLI oficial da Anthropic para interagir com Claude diretamente pelo terminal e dentro de IDEs.

## O que é o Claude Code?

[Claude Code](https://claude.ai/code) é uma ferramenta de linha de comando que permite:

- Editar arquivos e navegar pelo codebase com linguagem natural
- Executar comandos de terminal e testes
- Integrar com Git e GitHub
- Automatizar tarefas de desenvolvimento via hooks e agentes
- Conectar serviços externos via MCP (Model Context Protocol)

## Funcionalidades Exploradas

- [ ] Configuração inicial do Claude Code
- [ ] Integração com GitHub via MCP
- [ ] Criação e edição de arquivos
- [ ] Commits e pull requests automatizados
- [ ] Hooks e automações

## Como Usar

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- Conta na [Anthropic](https://www.anthropic.com/) com acesso ao Claude Code

### Instalação do Claude Code

```bash
npm install -g @anthropic-ai/claude-code
```

### Iniciando uma sessão

```bash
claude
```
